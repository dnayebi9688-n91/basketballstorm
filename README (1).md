# بسکتبال استورم | Basketball Storm

سایت حرفه‌ای پوشش لیگ NBA به زبان فارسی

**مالک:** دانیال نایبی

---

## ویژگی‌ها

- طراحی مدرن و حرفه‌ای با تم تیره NBA
- کاملاً راست‌چین و فارسی (فونت وزیرمتن)
- بخش نتایج زنده
- اخبار و مقالات
- لیست تیم‌های NBA
- آمار برترین بازیکنان
- **چت هوشمند AI** (استورم AI)
- بهینه‌سازی کامل SEO برای Google Search Console
- Structured Data (JSON-LD)
- robots.txt و sitemap.xml آماده

---

## نحوه استفاده

1. فایل‌ها را روی هاست آپلود کنید (یا با GitHub Pages / Netlify / Vercel منتشر کنید)
2. دامنه را به `basketballstorm.ir` یا دامنه دلخواه متصل کنید
3. در Google Search Console سایت را ثبت کنید و فایل sitemap.xml را ارسال کنید
4. robots.txt به صورت خودکار توسط گوگل خوانده می‌شود

---

## ساختار فایل‌ها

```
basketball-storm/
├── index.html      ← صفحه اصلی سایت
├── robots.txt      ← دستورات خزنده گوگل
├── sitemap.xml     ← نقشه سایت برای ایندکس
└── README.md       ← این فایل
```

---

## آماده‌سازی Google Search Console

1. به [Google Search Console](https://search.google.com/search-console) بروید
2. Property جدید اضافه کنید (دامنه یا URL prefix)
3. مالکیت را تأیید کنید (HTML tag یا DNS)
4. بخش Sitemaps → آدرس `https://yourdomain.com/sitemap.xml` را ارسال کنید
